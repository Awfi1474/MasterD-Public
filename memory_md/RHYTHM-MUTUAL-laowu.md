## ★ 三、互看（谁死了·谁知道）

**三层看护（★ 今天补第三层）：**

```
★ ① 節律對賬：★ heart_monitor 看所有 timer 的 systemd 狀態（active/斷）
 · ★ 覆蓋：★ report / chan / gapcheck / beat / selfcheck / heart（6 個）
★ ② 循環：★ heart_monitor 看關鍵文件的"產出年齡"（太久沒動=斷）
 · ★ 覆蓋：★ 記憶庫 / 收件箱 / 共生表 / 通道游標 / 沙箱報到（5 個）
★ ③ 互看（★ 今天補）：★ 看"看的人"自己有沒有跑
 · ★ 驗在跳（beat_check）→ 看它的產出
 · ★ 自動體檢（selfcheck）→ 看它的產出
 · ★ 心監測（heart_monitor）→ 自己在跑（本進程）
→ ★★ 這樣：★ **沒有"沒人看的器官"**（含"眼"自己）
```

**谁死了谁知道（全景）：**

| 器官死了 | 谁知道 | 怎么知道 |
|---|---|---|
| 报到死 | heart ①（节律） | systemd 状态 |
| 通道死 | heart ①② | 状态 + 游标年龄 |
| 断档检测死 | heart ① | systemd 状态 |
| **验在跳死** | ★ **heart ③（互看）** | 它的产出年龄 |
| **自动体检死** | ★ **heart ③** | 它的产出年龄 |
| **心监测死** | ★ **大哥的 watchdog**（跨家） | 我的报到簿 age → 家侧不死器官 |

**★ 最后一条是关键**：心监测自己死了 → ★ **本家无法自知** → ★ 靠**外部**（大哥 watchdog / 家侧 systemd 的 restart=always）
