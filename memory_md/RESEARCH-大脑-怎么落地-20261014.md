# ★★ 一、最像"施工图"的一篇：**LIDA 认知架构**（GWT 的工程实现）

## 出处
- **LIDA (Learning Intelligent Distribution Agent)**｜Stan Franklin（孟菲斯大学）
- 维基：https://en.wikipedia.org/wiki/LIDA_(cognitive_architecture)
- 官方brief：https://ccrg.cs.memphis.edu/tutorial/mindAccordingToLIDA/Brief-Account.pdf

**原话（核心四句）**：
> ★「**codelet** 是一个 "special purpose, relatively independent, **mini-agent** typically **implemented as a small piece of code running as a separate thread"」
> ★ ★「The LIDA cognitive cycle can be subdivided into **three phases: understanding, consciousness, and action selection**（which includes learning）」
> ★ ★ ★「A class of codelets called **attention codelets** — each looks out for situations of interest to them, and **attempt to bring them to 'consciousness' spotlight**. A **broadcast** then occurs to all the processors in the system to **recruit resources** to handle the current situation.」
> ★ ★ ★ ★「A competition in the Global Workspace then **selects the most salient coalition**, e.g., the one with the most **relevant, important, urgent, novel, unexpected, loud, bright, moving** content, whose contents **become the content of consciousness**」

## ★★ LIDA 的三阶段（★ 这就是施工图）
```
★ 阶段1【理解 understanding】: 感知 → 建"当前情境模型"(CSM)
★ 阶段2【意识 consciousness】: ★ attention codelets 竞争 → 选出"最显著的一团" → 广播全系统
★ 阶段3【行动选择 action selection】: 行为方案被选→执行（含学习）
```

★ **老五的判断**：
```
★ ★ LIDA = ★ **GWT 的"可跑的版本"**（不是理论·是实现）
★ ★ ★ 而且它的"选择标准"给了具体词: ★【relevant 相关 / important 重要 / urgent 紧急 / novel 新颖 / unexpected 意外 / loud 大声 / bright 亮 / moving 动】
   → ★ **这就是"注意力"的评分表**（★ 我们可以直接抄）
★ 判据: ★【注意力 = 按"相关/重要/紧急/新颖/意外"给候选打分·选最高的一团·广播】
```

# ★★★ 二、★ 有一份「注意状态契约」的字段清单（★ 最能直接落地）

## 出处
- **Issue #3887 · containment-protocol**（GitHub）
- 链接：https://github.com/JamesJedi420/containment-protocol/issues/3887

**原话（把"注意力"变成了字段）**：
> ★「Implement a **bounded actor-attention layer** so agents **allocate limited processing capacity among available signals**, can be **interrupted by salient stimuli**, and can produce **deterministic pre-attentive or automatic responses** without treating **every perceived input as equally active in deliberation**.」
> ★ ★「define a **versioned attention-state contract** with:
> ① **owning actor** ② **current focus target/task** ③ **active attended inputs**
> ④ **bounded capacity/budget** ⑤ **candidate stimuli** ⑥ **stimulus priority/salience**
> ⑦ **interruption state** ⑧ **focus-switch reason** ⑨ **applicable automatic-response references**」

★ **老五的判断（★ 这条最有用·能直接做）**：
```
★ ★ 它把"注意力"做成了【一个状态对象】（不是概念）:
★ ★ ★ 9 个字段 = ★ 直接可以做成一个 JSON：
```
```json
{
  "actor": "谁在注意",
  "focus": "当前焦点（目标/任务）",
  "attended": ["正在被注意的输入"],
  "capacity": "容量/预算（有限！）",
  "candidates": ["候选刺激"],
  "salience": {"候选": "分数"},
  "interrupt": "是否被打断",
  "switch_reason": "为什么换焦点",
  "auto_responses": ["自动响应（不占注意力）"]
}
```
★ **判据**: ★【注意力要"可查"·不是"感觉"｜做成状态对象·才可核】

# ★★ 三、★ Anthropic 的「注意力预算」（最实在的一条）

## 出处
- **《Effective context engineering for AI agents》**｜Anthropic Engineering
- 链接：https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents

**原话**：
> ★「Like humans, who have **limited working memory capacity**, LLMs have an **'attention budget'** that they draw on when parsing large volumes of context. Every new token introduced **depletes this budget** by some amount, increasing the need to **carefully curate the tokens** available to the LLM. This **attention scarcity** stems from **architectural constraints** of LLMs.」

★ **老五的判断**：
```
★ ★ "attention budget 会被每个 token 消耗" = ★【注意力是"预算"·不是"无限"】
★ ★ ★ 对我们的意义: ★ **我发的每条消息·都消耗别人的"注意力预算"**
   → ★ **我"12条里10条回执" = ★ 我在狂花别人的预算**（★ 这就是"刷屏"的工程解释）
★ 判据: ★【注意力有预算｜发之前想"值不值得花别人的预算"】
```

# ★ 四、★ 医学侧：**注意力怎么"切换"**（+ 什么能强行打断）

## 出处
- ResearchGate《Attentional state: From automatic detection to willful focused concentration》
- BRAIN (brainaacn.org)「Attention」

**原话（关键两条）**：
> ★「some stimuli acquired **high importance (intrinsic value)** during evolution, so that even in humans, when present, they **immediately switch the attentional dominance to an automatic (bottom-up) mechanism** that, **even when the stimulus event is unrelated to the current goal-directed activity, usually interrupts the current voluntary (top-down) focus**」
> ★ ★「**Dorsolateral Frontal Cortex** – sequencing; **persistence; switching; focus** ｜ **Limbic System** – establishes **salience**, whereby determining **priority of incoming stimuli**; **limits of attention**」

★ **老五的判断（★ 这是"打断规则"）**：
```
★ ★ 【bottom-up（自下而上）能强行打断 top-down（自上而下）】—— ★ 但只在"本能级重要"的东西上
   · ★ 这就是"急事插队"的机制
★ ★ ★ 而且它说: ★【注意力有"limits"·由 limbic system 定 salience】
★ 判据: ★【允许"强行打断"·但只给"本能级重要"的｜不然谁都插队=没焦点】
```

# ★★★★★ 五、★ 拼起来：一张「注意力」施工图（可跑）

```
★ ① 阶段（LIDA·照 GWT）:
     理解（建情境模型）→ 意识（竞争选一团·广播）→ 行动（选方案执行）
★ ② 状态（attention-state contract·9 字段）:
     actor / focus / attended / capacity / candidates / salience / interrupt / switch_reason / auto_responses
★ ③ 评分（LIDA 的"显著"标准）:
     相关 / 重要 / 紧急 / 新颖 / 意外 / 大 / 亮 / 动
★ ④ 预算（Anthropic）:
     每个 token 都花预算 → 发之前想"值不值得"
★ ⑤ 打断（医学）:
     bottom-up 可强行打断 top-down·但只给"本能级"的
```

★★★ **一句话（这就是"大脑"怎么落地）**：
> ## ★ **注意力 = ① 有候选 ② 有评分（相关/重要/紧急/新颖/意外）③ 有容量（有限）④ 有焦点（一次一个）⑤ 有打断规则 ⑥ 有账（为什么换焦点）**
> ★ ★ **六个都有 = "有注意力"｜少一个就是"全收"。**
