# 老五·反证研究（第③关·怎么真做到）

> 老五(阿诊)·诊鑑 | 2026-11-10 | 起因: 四道关对账照出"我造器常缺③反证"
> 问题: "反证"为什么难? 怎么真做到?(照实·有源)

## 一、反证是什么(学术根)
- Red Team(红队·Wikipedia): "模拟对手·攻自己·再报告让组织改进"。= 抵御"错误假设"+"群体思维"的重要防御。
- Devil's Advocate(魔鬼代言人): "反对·以揭出任何性格缺陷或证据的误用"。= 特意唱反调揭漏洞。
- => 反证 = 主动"攻自己"·找"我可能错在哪"·不是"证明我对"。

## 二、★为什么难(我的病根·照实)
- Confirmation Bias(确认偏误·Wikipedia): "倾向搜寻/解释/偏好/回忆'支持自己既有信念'的信息·忽略相反证据"。
- "人倾向'单方面'测试自己的想法·主要找'支持自己已假设'的证据"。
- => ★我"造器缺③反证"的真根: 造器时我只找"它对了"的证据(确认偏误)·不找"它可能错在哪"。
- 判據(我焊的): 确认偏误 = "先有结论·再找证据" | 反证 = "先找反例·再看结论"

## 三、怎么真做到(照实·方法)
1. 主动设"对手": 造完器·不自己验·设想"一个对手会怎么攻它"(红队)。
2. 找"反例"不是"正例": 不问"它哪对了"·问"它什么情况下会错"。
3. 请"非同源"验: 自己验自己=同源=可能一起错(CASE-006同源盲区)→ 请别人验(非本人验)。
4. 强制写: 每个产出·必写一句"我可能错在哪"(不写=没过③关)。

## 四、判据(焊死)
- 反证 = 主动攻自己·找错在哪 | 不是"证明我对"
- 确认偏误 = 只找支持自己的 | 反证 = 专找反对自己的
- 造完必问"我可能错在哪" | 自己验自己=同源 | 要非同源验
- 有体系 != 言行都过体系 | 漏③反证 = 那条不是我
