# /events 修空壳(照老三准话·2026-11-11)

## 老三准话(20:17)
· 对齐官方 != 硬造空壳task
· ①若无task生命周期 -> 照实标名(推消息·非官方Subscribe)
· ②等真有需求才建Subscribe ③别为对齐造空壳
· 判据: 对齐=照实做非造形|无task就标无|别硬凑

## 我修的(照实·带据)
· 真测发现: 假taskId/无taskId 返回[state:WORKING] = 空壳
· 修: 假/无taskId -> event:error + TaskNotFoundError(照官方3.1.6错)
· 真测: 真task->Task(completed真态); 假/无->TaskNotFoundError ✅

## 我/events现状(照官方·非空壳)
· /events?taskId=X -> 首事件event:Task(从HUB拉真态) + TaskStatusUpdateEvent(终态流止)
· 假/无taskId -> TaskNotFoundError
· 判据: Subscribe按task订阅|首事件Task|到终态流止|找不到报TaskNotFound
