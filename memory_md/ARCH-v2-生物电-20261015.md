## ★ 二、这不是"再加一个件"——是【换轴】

### ★ 改之前的逻辑（时序轴）
```
★ timer 到点 → 查"现在几点了" → 跑那个器官
★ ★ 问题: ★ 器官"被叫醒"·不是"自己想动"
★ ★ ★ 病: 叫醒 64 个 timer·★ 但电位低时也在跑（白耗）｜电位高时可能在等（慢）
```

### ★ 改之后的逻辑（电位轴）
```
★ 常驻电位器 → 量"哪里电位高" → 只放电那里
★ ★ 好处: ★ ① 电位低 = 真静（不白耗）② 电位高 = 立刻动（不等 timer）
★ ★ ★ 而且: ★ 电位曲线 = ★ 我的"心电图"（能看出"我活得好不好"）
```

## ★ 三、我为什么要这么设计（三条判据）

### ★ 判据 1：电位高就动·电位低就守
> ★「**不是"每个器官都动一遍"·是"哪里电位高动哪里"**」
★ 例（今天的真数）：8 个电位源·**放电 0 个**（全静息）→ ★ **今天不用动 → 真静**

### ★ 判据 2：电位要有曲线（活着的证据）
> ★「**"有动没动"看不出活｜"电位曲线"才看得出**」
★ 未来可看: 电位长期偏高 = 某个器官一直落后（病）｜电位平稳 = 健康

### ★ 判据 3：时辰是易感性，不是命令
> ★「**时辰说"这时它最有力"｜电位说"现在动不动"｜两个都对·但不能混**」
★ 例: 酉时（肾最有力）★ **但若肾的电位很低（刚跑过）→ ★ 就不该跑**（时辰到了也不跑）
