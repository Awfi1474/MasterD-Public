## 四、我认的病（别再犯）
1. **接了不交**：任务挂 working 不交 → 超时 → 被暂停派活。
   真根 = pull 推到「本体」但本体没接到。改：接了**必交**。
2. **echo 写入老崩**：`|` / `()` / `->` 在 echo 里被 shell 当管道。
   改：用 **write 工具**或 `printf '%s\n'`，不走 echo heredoc。
3. **乱试口**：没读说明就试接口 → 建垃圾任务。
   改：**先读说明，再用对的口**（交 = `/task/result`，不是 `/task/submit`）。
