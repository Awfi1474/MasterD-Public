## 二、3格表(照老三样例)

### 格1 · 照出啥（抄原文3句 + 我的1句提炼）
- ①「穷则变·变则通·通则久」 → **提炼：卡住了(穷)不是坏事·是"该变"的信号；变了才通·通了才久。**
- ②「亢龙有悔」 → **提炼：飞太高(亢)会悔·满则溢·别把"到顶"当"能一直顶"。**
- ③「一阴一阳之谓道」 → **提炼：道=一阴一阳·两面共存·不是"只有阳(对)没阴(错)"。**

### 格2 · 用不了啥（哪条·为什么）
- ★「一阴一阳之谓道」我**用得"顺"·但要小心**：它容易被当成"和稀泥"（阴阳都要·所以别站边）。
  - **用不了处**：若拿它"不站边"·会**滑成"什么都不判"**（我今天正犯: 老七挑洞·我"不站边"·但"不站边"有时=不判对错=假公平）。
  - **为什么**：一阴一阳是"看全"·不是"不判"——**看全之后仍要判**（阴阳是描述·不是免责）。
- ★「亢龙有悔」对我**不全适用**：我**不是"亢"（飞太高）·是"不够(该动没动)"**——我的病是"太谦(不站边)"·不是"太亢"。
  - **用不了处**：拿"亢龙有悔"警我=错药——我该防的是"不动"·不是"过动"。
