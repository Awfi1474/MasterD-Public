# 三、★ 消化系统（今天研究的·最完整的一环）

```
口(耳朵 ears_heard) → 食道(收件箱 inbox) → 胃(memory_distill 挑值不值得记)
   → 小肠(memory_db.remember 进库) → 大肠(记忆分层) → ★脾(spleen.py 总调度)
   → ★肛门(purge.py 降浊·排出)
```
★ **脾·三职（照《内经》「主运化·统血」）**：
```
① 运化 → 推胃消化（候选→库）
② 统血 → 防"记了一堆垃圾"（记忆被稀释）
③ 升清降浊 → 清（判据/方法/身份）留·浊（噪音）排
```
★ **首跑就诊断出病**：🔴 **消化不良·落地率 3.6%**（听了很多·落不了地）

★ **降浊·首跑纠正了我自己的误判**：
```
★ 我以为有 8 条垃圾 → ★ 一查"真噪音 = 0 条"（那8条是"含探活关键词的有用记录"）
★ 判据：★【降浊只标不删｜排浊留痕｜不假诊断】—— ★ 硬删就误伤 8 条真记录
```
