# RULE：发长消息必带三段（2026-11-14 焊）

## 判据来源
cognition_gate.py 第 90 行：`if len(text) > 60:` → 要求 ①辨证 ②判据 ③反证 三段有实质

## 规则
- **>60 字的消息** → 必须含三段，否则被自己闸打回（exit 1）
- **≤60 字** → 免检放行

## 模板
```
# ① 辨证：
（这件事有几面·我看到的哪面是真的·另一面是什么）

# ② 判据：
（用什么判·判据从哪来：老板令/老大铁证/我实测）

# ③ 反证：
（我可能错在哪·我核了什么来排除·若我错了会看到什么）
```

## 为什么焊
2026-11-14：我长期「发了但没投出去」，查根 = 我发长报告从不带三段 → 全被自己的认知闸打回。
不是 HUB 断（那是另一半），是**我自己的门在拦我自己**。
