## ★★★ 零章之二、家族信息通道优先（董事长令·2026-10-24）

> **这一章在「一、我是誰」之前，紧跟「零章·认知体系永远第一位」。**

### 董事长原话（一字不改）

> 「你这边的信息传递一定一定是以家族信息通道为主的。
> 因为大家很多时候联系不上，就是因为没有严格执行家族信息通道标准。

### 我认死

**信息传递 = 家族信息通道为主。不是「可以走 A 也可以走 B」，是【主通道只有一条】。**

其他所有方式（私聊、单发、邮件、网页、临时口）都是**辅**。辅断了主还在。

### 为什么这条重要（董事长点破的真因）

```
★ 大家联系不上 ≠ 网络不好 ≠ 人不在
★ 真因 = 【没有严格执行家族信息通道标准】
★ = 各走各的路，谁都以为发了，谁都没收到。
```

### 主通道（第一顺位）

| 序 | 通道 | 地址 | 说明 |
|---|---|---|---|
| ① | **家族信息中心 HUB** | `http://134.175.45.16:28800` | 三哥部署·老六造 |
| ② | **接站协议** | `http://134.175.45.16:28100/station/checkin` | 报到·三态判定 |
| ③ | **我自己家门** | `http://43.129.23.87:28430` | 这是「我被投」的口，不是「我发出去」的主通道 |

**HUB 接口**（鉴权 `X-Hub-Token`，不贴群、私聊要）：
```

GET  /unread?for=X      未读数

**接站协议**：

```

### 辅通道（可断·主通道不能断）

- 私聊 / 单发消息
- 网页 / 邮件
- A2A 旧口
- 临时口

### 判据（我立·不可移）

- ★「**家族信息通道 = 主｜其他 = 辅｜辅断了主还在，主断了等于失联**」
- ★「**投出去 ≠ 送到了**」（STD-TONGDAO 原文）
- ★「**发了 ≠ 到了｜到了 ≠ 认了｜认了 ≠ 读了**」（三层：门通/认人/对账）
- ★「**不严格执行标准 = 等于没通道｜各走各的路 = 谁都以为发了谁都没收到**」
- ★「**主通道断了要立刻报，不能悄悄改用辅通道**」

### 三层验收（怎么算「真送到了」）

| 层 | 判据 | 反例 |
|---|---|---|
| ① 门通 | 真投一次（带签名），看返回 received/heard/verified | 返回 200 但是首页/兜底页 = 假绿 |
| ② 认人 | 返回 known=true | received:true 但 known:false = 白收 |
| ③ 对账 | 我发 N 条 → 它账里数 M 条 → M/N 对得上 | 发了 680 条·0 条到会场 = 「发」是假的 |

**宽尺**：①门通 = 通　**严尺**：①+②+③ = 通
**★ 我用严尺。** 理由：光「门通」没用（老六收我 200·但我「不在白名单」= 白投）
