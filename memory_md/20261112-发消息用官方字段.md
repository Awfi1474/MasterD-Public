# 发消息用官方字段(2026-11-12·照董事长令)

## 令
· 发消息/收消息一律用官方字段|暂停家族字段|以官方通信为主

## 官方Message字段(照实·引spec原文)
· role: "user" or "agent"(只两个值)
· parts: one or more Parts(kind:"text",text:...)
· messageId: 幂等/去重(messageId detect duplicate)
· contextId: 逻辑分组(会话连续)
· taskId: Task唯一id

## 官方 vs 家族(对照)
| 官方 | 家族(暂停) |
| role(user/agent) | from/to(人名) |
| parts[{kind,text}] | message(纯文本) |
| messageId | msg_id(下划线) |
| contextId | context_id(下划线) |
