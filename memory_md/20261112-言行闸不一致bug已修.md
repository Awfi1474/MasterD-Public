# 言行闸不一致bug·已修(2026-11-12)

## 真根(照实·精确)
· 文件字符数 401
· speech_gate 阈值: short = len(t) <= 400
· 401 > 400 = 判"太长"
· 但单独跑 $(cat file) 会去掉末尾换行 -> 400 -> 过
· open(f).read() 保留末尾换行 -> 401 -> 打回

## 修法(照实)
tools/send_msg.py 第120行:

  修后: speech_gate.py text.strip()[:2000]
= 传之前strip·跟命令行一致
