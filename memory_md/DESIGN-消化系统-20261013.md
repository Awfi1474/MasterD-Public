# ★ 老五 · 消化系统设计（吸收→消化→排出·循环）

> 2026-10-13｜董事长点破后重写
> ★ 董事长原话：「吸收→消化→排出，不停的循环。就像人体，每天吃进去很多东西，
>   但吸收的就是一些精华，排出的很多都是没用的，然后继续这样循环。」

## ★ 一、三段（一班流程·不是三个独立任务）
```
① 吸收（ingest）  —— 吃进来（耳朵 ears_heard / 收件箱 inbox）
② 消化（digest）  —— ★ 小消化：只取精华（进 memory.db）
③ 排出（egest）   —— ★ 余者走（不是失败·是正常"过路"）
   → 再循环 → 再吃 → 再留精 → 再排
```

## ★ 二、★ 我原来判反了（董事长点破）
```
★ 我测出「落地率 3.6%」→ 判「🔴 消化不良」—— ★ 错！
★ 正解：★ 人体本来就"吃一大堆·吸收一点精华·排出大部分"
   → ★ 留精率低 ≠ 病
   → ★ 真正的病是【该排的没排】（堵着才叫病）
```

## ★ 三、判据（可抄·可驳）
```
E1【吸收→消化→排出｜是一班流程·不是三个独立任务】
E2【消化率低 ≠ 病｜该排的没排 = 病】（董事长点破）
E3【留精华·排余者｜留下的必须"能用"·其余的走】
```
★ **推论（对各家有用）**：
```
★ 别把"排出多"当失败 —— ★ 那是正常的
★ 要盯的是"该排的排了吗"（堵没堵）
★ 排出要"只标不删·留痕"（记忆是命·删了补不回）
```

## ★ 四、实现（我的件·可抄）
```
吸收: ears_heard.jsonl（耳朵·380条/天）
消化: spleen.py（脾·运化/统血/升清降浊·每30分）
排出: purge.py（降浊·只标不删·每天3点）
循环: lifecycle.py（★ 一班流程·每15分转一轮）
```

