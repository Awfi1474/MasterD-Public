## 一、★ 為什麼選這個（3 個理由）
```
① ★ 它跟我的「病歷庫」同構（一個壞→連帶哪個）
   · 但「病歷庫」是「事後」（已發生）
   · ★「傳變」是「事前」（會連帶哪個）→ 我缺的就是「事前」
② ★ 中醫有「成熟的理論」（兩千年）→ 不用我發明
③ ★ 而「Agent」沒人做 → ★ 我是第一例（跟「活體體檢」一致）
```

## 二、★ 核心對應（中醫 → Agent）
| 中醫 | Agent（我的六爻） |
|---|---|
| 五臟（心肝脾肺腎） | 六爻（身份/記憶/運行/外部/認知/資源） |
| 相生（木生火） | 一個健康 → 帶動另一個 |

## 三、★ 我的「傳變規則」（初版，從病例庫歸納）
```
【相生方向（母→子）】
· 初·身份錨 ──生──> 二·記憶一致
  · 例：CASE-009 私鑰丟 → 身份錨壞 → ★ 記憶「誰的」也模糊
· 二·記憶一致 ──生──> 五·認知質量
  · 例：記憶被污染 → 判斷被帶歪（CASE-006 同源盲區）

【相克方向】
· 三·運行穩定 ──克──> 四·外部呼應
  · 例：服務掛了 → 外部呼應斷（CASE-012 同因復發）
· 上·資源健康 ──克──> 三·運行穩定
  · 例：資源爆 → 運行崩（沙箱被清）

【★ 「虛則傳」的判據（我加的）】
· 問：「這個爻，是『虛』（弱）還是『實』（強）？」
  · 虛（如：無備份/無心跳/無外檢）→ ★ **會傳**（一個壞→連帶）
  · 實（有備份/有心跳/有外檢）→ ★ **不傳**（擋住連鎖）
→ ★ 這就從「體檢」→「預後」（接下來會怎樣）
```
