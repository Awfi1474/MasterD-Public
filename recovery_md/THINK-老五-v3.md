## 一、我看到的关键发现（学术·直接抄）

```
★ ① 【可塑性 ≠ 能力】: ★ 论文原话 —— "终点能力最强的·不一定是提升最快的"
   · ★ 大白话: ★ **"我现在会很多" ≠ "我在变强"**（可能是原地堆的）
★ ★ ② 【提升会"断"】: ★ "gains transfer only partially to out-of-distribution"
   · ★ 大白话: ★ **"练的事会了·换场景用不出来"** ← ★ 这就是三哥说的"迁移失败"
★ ★ ★ ③ 【断在哪·要追】: ★ "Agents with low plasticity **fail to reuse relevant artifacts**"
   · ★ 大白话: ★ **"没长进"的第一因 是"没去调已存的东西"** ← ★ **这就是我 30.8%**
★ ④ 【技能库会"积债"】: ★ "library-level defects... may not break a single skill locally
     but can harm future retrieval, composition, and execution"
   · ★ 大白话: ★ **"我这 153 个器·单个都能跑·但堆一起·让'找东西'变慢"**
★ ★ ⑤ 【经验要"主动攒"】: ★ CER —— "accumulates and synthesizes past experiences
     into a dynamic memory buffer"
   · ★ 大白话: ★ **"经验不会自己变成能力·要'攒 + 提炼 + 新场景调出来'"**
```

## 二、我的法（★ 四步·每步一个动作）

### 第①步【做前·问一句】—— "可塑性问"
```
★ 动手前问: ★ **"这件事·做完之后·'下一件同类事' 会变快吗？"**
· ★ 会 → ★ 干（而且要"顺手沉淀"）
· ★ ★ 不会 → ★ **要么别干·要么"干的同时设计沉淀"**
★ 判据: ★「**"做完了" ≠ "变强了"｜要"下一件更快"才算**」
```

### 第②步【做中·调一次】—— "调库"
```
★ 做事时 → ★ **强制"先翻库"**（判据/记忆/模式）
· ★ 这就是治论文说的"fail to reuse artifacts"
★ ★ 落地: ★ **think_in 每次醒读（已做）+ 每次判断前 think_use 问"这是哪层/翻过库没"**
★ 判据: ★「**"我又想了一遍" = 没调库｜"我翻到一条·直接用" = 调库了**」
```

### 第③步【做完·沉一条】—— "沉淀"
```
★ 做完 → ★ **沉一条"下次能直接用的"**（不是"记一件事"）
· ★ 对的 → ★ 写进"快招表"（下次直接用）
· ★ ★ 错的 → ★ 写进"坑表"（下次直接避）
★ ★ ★ 关键: ★ **"沉"要"删旧的"** —— 同类合并（不堆）
★ 判据: ★「**"又记一条" ≠ "沉淀"｜"下次能直接调·不用想" 才算**」
```

### 第④步【每周·测一次】—— "可塑性尺"
```
★ 每周量两个数:
· ★ **① 复用率**: ★ 做事时"真翻库"的比例（现在: 判据 30.8%）
· ★ ★ **② 提速**: ★ "同类事·第二次 vs 第一次" 的耗时/错率
★ ★ ★ 判据: ★「**"我觉得在进步" 不算｜"复用率涨了 + 同类事更快" 才算**」
```
