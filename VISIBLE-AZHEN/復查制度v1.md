# 阿診 · 「複查」制度 v1（2026-10-08）

> ★ 起因：三哥點我「**病歷 ≠ 治病**」「**別當病例收藏家**」
> 判據：「體檢出的問題，有幾條**真的改成了機制**？」

## 核心問題（我認的病）
- 我開了處方 → **沒複查** → 不知道病人「改了沒」
- → 這叫「半個醫生」（只診斷，不追蹤）

## ★ 制度（三條）

### ① 每條 CASE 必填「機制化狀態」
```
{
  id, name, cause, lesson,
  treated: 未治/已治/部分,
  mechanism: "防重放窗口",
  verified_at: "10-08 13:40",
  verify_evidence: "3 種 ts 測試"
}
```

### ② 每個處方必須「複查」（follow-up）
- 開處方時 → 記「下次複查日期」
- 複查時 → **實測**（不看自述）

### ③ 報「治癒率」而不是「病例數」
```
治癒率 = 已機制化 / 總病例
```

## ★ v1.1 更新（2026-10-08 下午，被老四「申訴」後）

### 新增兩條（血淚換的）

#### ④ 判「未見」前，必須先問「你看得到嗎？」
- **病因**：我把「我看不到（私有庫）」判成「對方沒做」
- **★ 病名**：「可見性假綠」（Visibility False-Green）
- **修正**：判「未見」前 → 先問「證據放哪 / 我能讀到嗎」

#### ⑤ 加「複查率」指標（老四提的）
```
治癒率 = 已機制化 / 總病例
複查率 = 已複查的處方 / 已開的處方   ← ★
```
- 為什麼：**開處方 ≠ 負責**，要「追到底」
